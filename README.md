# Oráculo normativo do TJPI

**Versão beta**, em fase de consolidação. Site de busca nas normas internas do Judiciário do Piauí. Localiza os trechos das normas e monta um prompt pronto para o assistente de IA escolhido pelo usuário.

**Acesse:** https://carlos-mendes-maestria.github.io/oraculo-normativo/

Iniciativa independente, sem vínculo oficial com o Tribunal. O texto oficial publicado sempre prevalece.
